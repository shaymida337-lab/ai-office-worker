## הפעלה (פעם ראשונה)

1. מתקינים Node.js בגרסה 20 ומעלה מהאתר https://nodejs.org (כפתור LTS). מתקינים פעם אחת בלבד.
2. **Windows:** לוחצים פעמיים על `start-windows.bat`.
   **Mac/Linux:** פותחים טרמינל בתיקייה ומריצים `npm start`.
3. פותחים בדפדפן את http://localhost:4610.

כדי שהמתזמן יעבוד, החלון השחור צריך להישאר פתוח. סוגרים אותו כדי לכבות את המערכת.

## עבודה יומיומית

1. **קבוצות וערוצים:** מוסיפים קבוצות פייסבוק שאתם חברים בהן, ומסמנים "קראתי את כללי הקבוצה, ופרסום עסקי מותר בה".
2. **לוח פרסומים ← "תכנן שבוע":** המערכת יוצרת לכל קבוצה פוסט חדש (וריאציה שונה) ומועד מותר. המועדים מדלגים על שבת וחג ושומרים על תדירות.
3. **"אשר את כל הטיוטות":** אחרי שקראתם את הטיוטות.
4. כשמגיע המועד, המשימה מופיעה ב**לוח הבקרה**. לוחצים **"העתק ופתח"**, הפוסט מועתק והקבוצה נפתחת. מדביקים, מפרסמים ולוחצים **"סמנו כפורסם"**.
5. כשמישהו פונה, רושמים **ליד** ומדביקים את הודעת הוואטסאפ. הקוד שבהודעה (למשל `B1003`) משייך את הליד לפוסט ולקבוצה.
6. **סטטיסטיקות:** בודקים אילו קבוצות מביאות לידים ומשהים את אלה שלא.

**כפתור אדום "עצור את כל הפרסומים"** בראש המסך: עוצר הכול מיד, וגם חוסם פתיחת משימות. לוחצים שוב כדי לחדש.

### למה הפרסום בקבוצות ידני?
Meta סגרה את ה-Groups API באפריל 2024, ולכן אין היום דרך רשמית לפרסם אוטומטית בקבוצות.
כל כלי אחר שמפרסם בקבוצות עושה זאת באמצעות אוטומציית דפדפן או התחזות לאדם. זה מפר את תנאי השימוש של Meta ומסכן את החשבון.
לכן המערכת **לא** עושה את זה: היא מכינה את הפוסט, פותחת את הקבוצה, והפרסום עצמו נשאר אצלכם.

## לידים ו-UTM
- כל פוסט מקבל קוד (`B1001`, `B1002`, ...). הקוד מופיע בהודעת הוואטסאפ המוכנה. בקבוצות שאוסרות קישורים מופיע בטקסט: "ציינו קוד ...".
- קישורים לאתר (לא חובה) כוללים UTM: ‏`utm_source=facebook`, ‏`utm_medium=group`, ‏`utm_campaign=שירות_אזור_חודש`, ‏`utm_content=קוד`.
- **בדיקות QA לא נספרות.** אלה לידים שנרשמו עם מספר העסק עצמו, עם קוד `QA-...`, עם המילה "בדיקה"/"test" או שסומנו ידנית.
  כפתור "קישורי בדיקה" בכל פוסט מייצר קישורים מסומנים כ-QA.

## דף פייסבוק עסקי (Meta Graph API)
- בלשונית "חיבורים" מזינים את Page ID ואת ה-Page Access Token **בטופס המקומי**, לא בצ'אט ולא בשום מקום אחר.
  הם נשמרים ב-`data/secrets.json`: לא בגיט, לא בגיבויים, ולא מוצגים שוב במלואם.
- הכפתור **"בדוק חיבור והרשאות"** שולח רק בקשות קריאה (GET). הוא בודק:
  - שהטוקן בתוקף ומה סוגו;
  - שהדף הוא אכן הדף של העסק;
  - שקיימות ההרשאות `pages_manage_posts` ו-`pages_read_engagement`;
  - בטוקן משתמש: שיש למשתמש הרשאת `CREATE_CONTENT` בדף.
- **פרסום חי נשאר כבוי.** כדי להפעיל אותו צריך גם `BRAKHA_ALLOW_LIVE=1` בקובץ `.env`, וגם להקליד "מאשר פרסום חי" בהגדרות.

## דוח לידים
לשונית "דוח לידים" מציגה את הלידים **לפי מקור, קבוצה, פוסט ועיר**: כמה לידים, כמה נוצר איתם קשר, כמה קיבלו הצעה, כמה נסגרו ומה שווי העבודות.
אפשר לסנן לפי טווח תאריכים ולייצא ל-CSV. לידים מהאתר שמגיעים עם `utm_content=B1001` משויכים אוטומטית לפוסט ולקבוצה.

## ייצוא וגיבוי
- **ייצוא:** גיבוי מלא ב-JSON, וקובצי CSV של לידים, דוח, פוסטים והיסטוריה. העברית מוצגת תקין באקסל.
- **גיבוי אוטומטי** יומי בתיקייה `data/backups`. נשמרים 30 גיבויים אחרונים, ואפשר גם ליצור גיבוי ידני.
- **שחזור:** מקלידים "שחזר" ובוחרים קובץ. לפני השחזור נשמר גיבוי של המצב הנוכחי, ואחריו המערכת חוזרת תמיד למצב סימולציה.

## חיבורים חסרים
1. **אנליטיקס באתר:** באתר אין כרגע כלי מדידה, ולכן ביקורים מ-UTM לא נמדדים. התקנת Google Analytics 4 היא בחינם, אבל דורשת שינוי באתר. השינוי לא בוצע, ויבוצע רק באישורכם.
2. **דף עסקי בפייסבוק:** צריך טוקן לדף, והמדריך המלא נמצא בלשונית "חיבורים". הטוקן נשמר רק במחשב שלכם, והבדיקה היא קריאה בלבד.
   פרסום חי מחייב גם `BRAKHA_ALLOW_LIVE=1` בקובץ `.env` וגם הקלדת "מאשר פרסום חי".
3. **מפתח Google לגיליון:** עד שמעלים מפתח, אפשר לייבא קובץ CSV.
4. **אינסטגרם / גוגל עסקים:** לא מחוברים, ונשארים ערוצים ידניים.
