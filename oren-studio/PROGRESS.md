דגימות: `samples/voice/*.mp3`.

## 3. הנפשה – השוואה בפועל
| מודל | מה עושה | זמן CPU | איכות | סטטוס |
|---|---|---|---|---|
| LivePortrait (PyTorch, CPU) | העברת תנועת ראש/עיניים/הבעות מוידאו מניע, 512px | **~5 שניות לפריים** (60 פריימים = 5 דק') | חדה, זהות נשמרת, עיניים טבעיות | איכות ✓ מהירות ✗ – 45 שניות ≈ שעתיים |

צווארי בקבוק ופתרונות מתוכננים למהירות:
1. FasterLivePortrait (ONNX Runtime CPU) – צפי ×2–3.
2. רינדור ב-12.5fps ואינטרפולציה ל-25 (RIFE) – חצי מהפריימים.
3. הנפשה רק של אזור הפנים (512) והדבקה לפריים 1080 מוכן מראש.
4. GPU חינמי: Kaggle (‏30 שעות T4 בשבוע, חינם) – דורש מפתח API חינמי של המשתמש; HF ZeroGPU – דורש טוקן HF חינמי.

## 4. החלטות
- קול: Phonikud → Chatterbox Multilingual (מקומי, חינמי, קוד פתוח). Avri = גיבוי מהיר.
- הנפשה: LivePortrait = מנוע תנועה ראשי (ראש/עיניים/הבעות). שפתיים: יתווסף מנוע אודיו→שפתיים (MuseTalk / Wav2Lip+שיפור).
- גוף וידיים: לא אפשרי באיכות גבוהה על CPU בלבד; מתוכנן דרך Kaggle GPU (InfiniteTalk / Wan-S2V) או וידאו מניע אמיתי.
