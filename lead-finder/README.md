# Lead Finder — ברכה והצלחה שיפוצים

מערכת לאיתור כתובות מייל עסקיות **פומביות** מאתרים רשמיים של עסקים באזור גוש דן
(תל אביב, רמת גן, גבעתיים, חולון, בת ים, קריית אונו, פתח תקווה).

תחומים: אדריכלים, מעצבי פנים, ניהול נכסים / ועדי בתים, חברות אחזקה, משרדי תיווך, מוסדות (בתי אבות / דיור מוגן, גני ילדים ומעונות).

## איך זה עובד

| שלב | קובץ | מה הוא עושה |
|-----|------|-------------|
| 1. איתור אתרים | `discover_dcoil.py`, `discover_b144.py` | קורא דפי קטגוריה/עיר פומביים במדריכי העסקים (דפי זהב, B144) **רק כדי למצוא את כתובת האתר הרשמי** של כל עסק. robots.txt נבדק לכל כתובת. מיילים לא נלקחים מהמדריכים. |
| 2. איסוף ואימות | `crawler.py` | נכנס לאתר הרשמי (דף הבית + עד 5 עמודי צור קשר/אודות), מחלץ מיילים, מאמת ושומר. |

### כללים שנאכפים בקוד
- כיבוד robots.txt; אתר שמחזיר 401/403/429/captcha — מדולג, בלי ניסיון לעקוף.
- לא מפענחים הסתרת מיילים (למשל Cloudflare email protection), אין התחברות, אין טפסים.
- רק כתובות שמופיעות באתר העסק עצמו, בדומיין העסק או ספק חינמי (gmail וכד') שהעסק פרסם.
- כתובות אישיות של עובדים (מעמודי צוות), כתובות גיוס/פרטיות ו-noreply — מוחרגות.
  נשמרת כתובת כללית (info/office/contact...) או הכתובת הראשית שהעסק פרסם לפניות.
- **אימות לכל כתובת:** תחביר תקין + לדומיין יש רשומת MX (או A) ב-DNS + הכתובת מופיעה בפועל בעמוד המקור (הקישור נשמר בעמודת "מקור").
- הסרת כפילויות גלובלית (מייל ודומיין), השוואה מול `data/blocklist.csv` ו-`data/previous_contacts.csv`.
- שמירת התקדמות (state + Excel) כל 25 עסקים — אפשר לעצור ולהמשיך מאותה נקודה.

## הרצה
```bash
pip install requests beautifulsoup4 openpyxl
python3 discover_dcoil.py 20        # 20 = מספר עמודי רשימה מקסימלי לכל קטגוריה×עיר
python3 discover_b144.py
python3 crawler.py --workers 10 --target 200
```
פלט: `output/business_leads.xlsx` (גיליונות: לידים מאומתים, הוחרגו, אתרים שנסרקו, סיכום) ו-`output/state.json`.

### רשימות חסימה ופניות קודמות
- `data/blocklist.csv` — עמודה `email_or_domain` (מייל מלא או דומיין שלם). כל מי שביקש להסיר — לכאן.
- `data/previous_contacts.csv` — עמודה `email`. כתובות שכבר פנינו אליהן.
