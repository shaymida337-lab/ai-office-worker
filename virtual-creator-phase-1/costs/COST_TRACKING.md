## Cost Optimization Strategies

### For Round 1
- Use lowest-cost suitable model for first-pass
- Start with 5-second duration (not longer)
- Minimize retries (get it right first time)
- Use reference images effectively (quality references = better first-pass)

### For Future Phases
- Batch similar content for efficiency
- Negotiate volume pricing if volume increases
- Monitor cost-per-approved-second metric
- Optimize model selection based on quality/cost trade-off
